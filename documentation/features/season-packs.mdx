---
title: Season packs
description: When you create a torrent, mkbrr looks for missing episodes in a TV season pack.
icon: tv-retro
---

<Note>
Each time you run `mkbrr create`, mkbrr looks at the video files in the content. If the content is a season pack with missing episodes, mkbrr shows a warning before it hashes the files.
</Note>

<CardGroup cols={2}>
  <Card title="Video files" icon="film">
    mkbrr counts episodes only in files with these extensions (any case):
    - `.mkv`
    - `.mp4`
  </Card>
  <Card title="Episode patterns" icon="list-ol">
    mkbrr reads episode numbers from these file name patterns:
    - Single: `S01E01` (the episode number has 1 to 3 digits)
    - Range: `S01E01-E03` or `S01E01-03` (all episodes from the first to the last)
    - Multi: `S01E01E02` (mkbrr reads the first two numbers only)
  </Card>
</CardGroup>

<AccordionGroup>
  <Accordion title="Season detection patterns" icon="magnifying-glass">
    mkbrr looks for the season number in the folder path of the first file. It uses patterns such as these:

    ```plaintext
    Show.S01.Complete
    Show.Season.01
    Show.S01
    Show-S01-1080p
    /Season 01/
    /S01/
    Show.S01.1080p
    Season 01/
    ```

    If no folder pattern matches and the content has more than one file, mkbrr looks for `S01` in the names of the first five files.

    <Info>
    Season detection is case-insensitive. The season number has 1 or 2 digits. Each pattern accepts only the separators in the examples above.
    </Info>
  </Accordion>

  <Accordion title="How the completeness check works" icon="check">
    mkbrr finds the highest episode number, and counts the unique episodes in the video files. The content is a season pack only if it has more than one unique episode. A pack is incomplete when an episode from 1 to the highest number is missing.

    <Warning>
    mkbrr cannot find missing episodes after the highest episode in the pack. A pack that starts after episode 1, for example at `S01E05`, shows episodes 1 to 4 as missing. mkbrr ignores episode 0 (`S01E00`).
    </Warning>
  </Accordion>

  <Accordion title="Example warning output" icon="triangle-exclamation">
    mkbrr shows the warning after the file list and before the progress bar. `--quiet` and `--info-only` hide it.

    ```plaintext
    Warning: Possible incomplete season pack detected
      Season number: 1
      Highest episode number found: 4
      Episodes found: 3
      Missing: episode 3

    This may be an incomplete season pack. Check files before uploading.
    ```
  </Accordion>
</AccordionGroup>

## Stop on an incomplete pack

If you give `--fail-on-season-warning`, mkbrr stops with an error when the pack is incomplete. It stops before it hashes the files, and it writes no torrent. This also works with `--quiet`. In a preset or a batch job, use `fail_on_season_warning: true`. In the GUI, turn on "Fail on season warning" on the Create page.

<Note>
The check finds common packaging mistakes, but it can miss some. Examine your files before you upload them to a tracker.
</Note>
