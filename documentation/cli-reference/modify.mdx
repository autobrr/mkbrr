## Usage

```bash
mkbrr modify [flags] [torrent files...]
```

<Note>
`modify` changes only the fields that you set. It keeps the other keys in the info dictionary, including custom keys. It drops unknown top-level keys, which are keys outside the info dictionary that mkbrr does not know. When `modify` changes something, it sets the creation date to now, unless you remove the date with `--no-date` or a preset. If no value changes, `modify` writes no file and prints "no changes needed". A value that the torrent already has is not a change. `--dry-run` uses the same rule.
</Note>

## Arguments

-   `[torrent files...]`: (Required) One or more paths to the `.torrent` files to modify.
