## Usage

```bash
mkbrr modify [flags] [torrent files...]
```

<Note>
`modify` keeps the existing metadata and changes only the fields that you set. If no value changes, `modify` writes no file and prints "no changes needed". A value that the torrent already has is not a change. `--dry-run` uses the same rule.
</Note>

## Arguments

-   `[torrent files...]`: (Required) One or more paths to the `.torrent` files to modify.
