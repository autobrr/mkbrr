### Input & Output

<ParamField query="--tracker, -t" type="string[]">
  Replace all trackers with these URLs. You can give this flag more than one time.
</ParamField>

<ParamField query="--no-tracker" type="boolean" default={false}>
  Remove all trackers. Use it to share a torrent without your passkey, or to make a torrent that finds peers only through DHT (the peer network that works without a tracker).
</ParamField>

<ParamField query="--remove-tracker" type="string[]">
  Remove the trackers on a host, and keep the other trackers. Give a host, such as `old.example`, or a full tracker URL. mkbrr then uses the host of the URL. The match ignores case and the port. It does not match a different host that contains the host, such as `gold.example` or `sub.old.example`. You can give this flag more than one time.

  The other trackers keep their order and their tiers. A tier is a group of trackers in the announce-list. mkbrr removes a tier that becomes empty. The main tracker is the `announce` URL. If you remove it, the next tracker becomes the main tracker.

  If a host matches no tracker, mkbrr prints a warning, such as `old.example: no matching tracker`, and continues with the other files. If nothing else changes, mkbrr writes no file for that torrent.
</ParamField>

<Note>
  You can use only one of `--tracker`, `--no-tracker`, and `--remove-tracker`. Each of them makes mkbrr ignore the `trackers` value of the preset. The info hash does not change, because the trackers are outside the info dictionary.
</Note>

<ParamField query="--name" type="string">
  Set the torrent's internal name.
</ParamField>

<ParamField query="--output-dir" type="string">
  Output directory for modified files.
</ParamField>

<ParamField query="--output, -o" type="string">
  Custom output filename (without extension).
</ParamField>

<Warning>
  When modifying multiple torrents, using `--output` with a fixed filename will cause subsequent files to overwrite the previous ones. Use `--output-dir` instead for batch modifications to preserve all modified files with unique names.
</Warning>

### Torrent Internals

<CommonPrivate />

<ParamField query="--no-private" type="boolean" default={false}>
  Remove the private flag entirely.
</ParamField>

<CommonEntropy />

<ParamField query="--no-entropy" type="boolean" default={false}>
  Remove the `entropy` key from the info dictionary. The info hash changes. If the torrent has no `entropy` key, mkbrr does not change the file. You cannot use this flag together with `--entropy`.
</ParamField>

### Seeding & Metadata

<ParamField query="--web-seed, -w" type="string[]">
  Replace all web seeds with these URLs. You can give this flag more than one time.
</ParamField>

<ParamField query="--no-web-seed" type="boolean" default={false}>
  Remove all web seeds. mkbrr ignores the `webseeds` value of the preset. You cannot use this flag together with `--web-seed`.
</ParamField>

### Execution & Output Control

<CommonVerbose />

<CommonQuiet />

<ParamField query="--skip-prefix" type="boolean" default={false}>
  Leave out the filename prefix from the output filename. The filename prefix is the preset name when you give a preset. Otherwise, it is the domain of the first `--tracker` URL, or `modified` when you give no `--tracker`. A preset `skip_prefix: true` also leaves it out.
</ParamField>

<ParamField query="--dry-run, -n" type="boolean" default={false}>
  Show what would be modified without making changes.
</ParamField>
